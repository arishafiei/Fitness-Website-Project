# Shapeup – Fitness & Health Web Application

A complete fitness website developed during my 8-week internship (Computer Programming Workshop) at FH Aachen University of Applied Sciences, Campus Jülich.

## Features

- **BMI Calculator** – interactive PHP-based body mass index calculation
- **Calorie Tracking** – log and track daily calorie intake with PHP backend
- **Workout Guides** – muscle building and stretching exercise pages
- **Diet Plans** – vegan, vegetarian and non-vegetarian weekly meal plans
- **Coaches Page** – trainer profiles and contact info
- **Image Carousel** – custom JavaScript slideshow
- **Responsive Design** – custom CSS styling across all pages

## Technologies Used

- HTML5 / CSS3
- PHP (forms, calculations, sessions)
- JavaScript (carousel, interactivity)
- XAMPP / phpMyAdmin
